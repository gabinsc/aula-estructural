# Aula Estructural

- Mantener TypeScript estricto y separar dominio, geometría, herramientas y React.
- Guardar coordenadas físicas globales en metros. Trabajar con newtons, newton-metro y radianes internamente cuando corresponda.
- Documentar las transformaciones geométricas y comprobar sus invariantes con Vitest.
- Mantener independientes las tolerancias físicas y las tolerancias de selección en píxeles CSS.
- Conectar barras únicamente mediante IDs de nudos compartidos. Un cruce geométrico conserva la conectividad existente.
- Mantener Vite compatible con GitHub Pages y verificar tipos, pruebas y compilación antes de entregar.
- Implementar únicamente los hitos autorizados. Consultar la hoja de ruta para conocer los límites del hito.
